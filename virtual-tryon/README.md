# White-label Virtual Try-On (Live + Photo)

Self-hosted, brand-neutral virtual try-on you fully own. Two modes:

- **Photo try-on** — one still image in, dressed image out. Runs on an open,
  commercially-licensed model (FASHN VTON v1.5, Apache-2.0). This is the
  low-cost workhorse for the free trials.
- **Live try-on** — real-time camera stream. Two backends behind one interface:
  - `decart` — Decart's hosted Lucy VTON, white-labelled (ship this at launch).
  - `local` — our own real-time pipeline (StreamDiffusionV2 + pose/segmentation
    + FlashVSR sharpening) running on a rented GPU. This is what removes the
    per-second fee and the "Generated by AI" watermark once it is good enough.

The web/VPS layer (site, store widget, logins, limits, consent, recording)
stays on your server. Only the heavy frame work runs on the GPU box. Shoppers
never see Decart or any upstream — it is your brand end to end.

## Why this architecture
- **Cost:** Decart live = ~$0.02/sec (~₹6,000/hr of camera time). A rented GPU
  running our `local` backend is ~₹30–250/hr regardless of how many seconds.
- **Ownership:** the `local` backend has no third-party watermark and no ToS
  limiting what you do with it.
- **Data:** every trial (with consent) is recorded to build our own training
  set, so the `local` backend keeps improving.

## Repository layout
```
server/      FastAPI app: session tokens, photo endpoint, limits, consent, recording
pipeline/    The ML pieces: garment prep, pose+segmentation, photo try-on, live engine, upscaler
webrtc/      Real-time transport for the live mode
web/         Minimal demo client (camera + garment picker)
scripts/     Model downloads, local run, RunPod deploy guide
data/         Recorded clips (consented) and prepared garments (gitignored)
```
