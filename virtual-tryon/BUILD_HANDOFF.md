## 0. The one-paragraph summary

We are building a **self-hosted, white-label virtual try-on** product for
e-commerce stores, with two modes: **Photo** (one image in → dressed image out)
and **Live** (real-time camera). Live has two interchangeable backends:
`decart` (Decart's hosted Lucy VTON, white-labelled — ship this at launch) and
`local` (our own GPU pipeline — StreamDiffusionV2 + pose/segmentation +
FlashVSR — which removes the per-second fee and the "Generated by AI" watermark
once it is good enough). The web/VPS layer owns the site, store widget, logins,
spend limits, consent and recording; only heavy frame work runs on a rented GPU.
Shoppers only ever see our brand.

## 1. Hard constraints and honest expectations

- **No illegal routes.** We do not attack, reverse-engineer intrusively, or
  extract Decart's model. The `local` backend is built from open, properly
  licensed components. This is settled; do not revisit it.
- **"Free" means no per-second fee, not ₹0.** The `local` backend runs on a
  rented GPU (~₹30–250/hr). There is no free GPU that serves real customers
  reliably.
- **v1 of `local` will be rougher than Decart** on fast motion and fine
  prints/logos — the research literature says garment detail is the hardest
  thing to hold in live video. Plan: launch on `decart`, improve `local` in
  parallel, switch stores over per-garment as quality allows.
- **The "Generated by AI" watermark** is stamped by Decart on *their* output.
  We do not strip it from their stream (their ToS + AI-transparency). Our
  `local` backend simply has no watermark. That is the fix.
- **Consent is mandatory** before recording any camera video (India DPDP Act
  2023): explicit opt-in, stated purpose, deletion on request, no under-18s.
  Until Decart's ToS on training from output is confirmed, record **inputs
  only** (shopper clip + garment + metadata), never Decart's output frames.

## 2. Component choices (all verified open + commercial where it matters)

| Job | Choice | License | Notes |
|---|---|---|---|
| Real-time video diffusion | StreamDiffusionV2 | Apache-2.0 | ~58 fps on H100-class w/ TensorRT |
| Step-speed trick | LCM-LoRA + TensorRT | open | 13–60× speedup; the same idea Decart distills |
| Pose + body mask | MediaPipe BlazePose (seg mask) | Apache-2.0 | 30–50 fps; fallback YOLO26-pose |
| Person/garment cutout | rembg (U2Net) / SAM2 | permissive | rembg is CPU-fine for garment prep |
| Sharpen / de-blur | FlashVSR | check repo | one-step streaming upscaler, CVPR 2026 |
| Photo try-on | FASHN VTON v1.5 | Apache-2.0 | ~5s/image, maskless, commercial OK |
| Live transport | WebRTC (aiortc) | open | same transport class Decart uses |

Decart's Lucy is a **causal/autoregressive diffusion model distilled to 1–4
steps** (Self-Forcing → CausVid → Causal Forcing lineage) with drift control.
We reproduce the architecture class with StreamDiffusionV2; the gap is training
data + tuning, not secret math.

```python
"""Consent gate + recording of trial INPUTS (not Decart output) for training."""
from __future__ import annotations

import json
import time
import uuid
from pathlib import Path

from .config import settings


class ConsentError(Exception):
    pass


def new_trial_id() -> str:
    return uuid.uuid4().hex


def require_consent(consented: bool, is_adult: bool) -> None:
    if not settings.recording_enabled:
        return
    if not consented:
        raise ConsentError("Recording requires opt-in consent.")
    if not is_adult:
        raise ConsentError("Recording is not allowed for users under 18.")


def record_trial(trial_id: str, store_id: str, garment_path: str,
                 camera_clip: bytes | None, meta: dict) -> None:
    """Persist only what we are allowed to: shopper input clip + garment + meta.
    Never writes upstream (Decart) output frames unless RECORD_OUTPUT_FRAMES."""
    base = Path(settings.recordings_dir) / store_id / trial_id
    base.mkdir(parents=True, exist_ok=True)
    (base / "meta.json").write_text(json.dumps({
        "trial_id": trial_id, "store_id": store_id, "ts": time.time(),
        "garment_path": garment_path, **meta,
    }))
    if camera_clip is not None:
        (base / "camera.webm").write_bytes(camera_clip)


def purge_expired() -> int:
    """Delete recordings older than retention window. Returns count removed."""
    cutoff = time.time() - settings.recording_retention_days * 86400
    removed = 0
    root = Path(settings.recordings_dir)
    if not root.exists():
        return 0
    for meta in root.rglob("meta.json"):
        try:
            ts = json.loads(meta.read_text()).get("ts", 0)
        except Exception:
            continue
        if ts < cutoff:
            for f in meta.parent.iterdir():
                f.unlink(missing_ok=True)
            meta.parent.rmdir()
            removed += 1
    return removed
```

### pipeline/garment.py
```python
"""Automated garment prep: background removal + category guess. CPU-friendly."""
from __future__ import annotations

import io
from pathlib import Path

from PIL import Image

_CATEGORY_HINTS = {
    "tops": ["shirt", "tee", "t-shirt", "top", "blouse", "hoodie", "jacket",
             "sweater", "kurta"],
    "bottoms": ["jeans", "trouser", "pant", "short", "skirt", "legging"],
    "one-pieces": ["dress", "gown", "jumpsuit", "saree", "sari", "robe"],
}


def guess_category(name: str) -> str:
    n = name.lower()
    for cat, words in _CATEGORY_HINTS.items():
        if any(w in n for w in words):
            return cat
    return "tops"  # safe default; store can override in the widget


def prepare_garment(raw: bytes, filename: str, out_dir: str) -> dict:
    """Remove background, normalize, save. Returns metadata for the widget."""
    try:
        from rembg import remove  # lazy import; heavy
        cut = remove(raw)  # bytes PNG with alpha
        img = Image.open(io.BytesIO(cut)).convert("RGBA")
    except Exception:
        # Fallback: keep original if rembg unavailable (e.g. during CPU-only dev)
        img = Image.open(io.BytesIO(raw)).convert("RGBA")

    # Flatten onto white for models that expect RGB product shots.
    bg = Image.new("RGBA", img.size, (255, 255, 255, 255))
    flat = Image.alpha_composite(bg, img).convert("RGB")
    if max(flat.size) > 1024:
        flat.thumbnail((1024, 1024))

    out = Path(out_dir)
    out.mkdir(parents=True, exist_ok=True)
    stem = Path(filename).stem or "garment"
    path = out / f"{stem}.png"
    flat.save(path)
    return {
        "garment_path": str(path),
        "category": guess_category(filename),
        "width": flat.width,
        "height": flat.height,
    }
```

### pipeline/pose.py
```python
"""Pose + body segmentation mask via MediaPipe. CPU ok, faster on GPU."""
from __future__ import annotations

import numpy as np


class PoseExtractor:
    def __init__(self):
        import mediapipe as mp
        self._seg = mp.solutions.selfie_segmentation.SelfieSegmentation(
            model_selection=1)
        self._pose = mp.solutions.pose.Pose(
            model_complexity=1, enable_segmentation=True,
            min_detection_confidence=0.5)

    def body_mask(self, rgb: np.ndarray) -> np.ndarray:
        """Return a float mask [H,W] in 0..1 where the person is."""
        res = self._seg.process(rgb)
        if res.segmentation_mask is None:
            return np.ones(rgb.shape[:2], dtype=np.float32)
        return res.segmentation_mask.astype(np.float32)

    def landmarks(self, rgb: np.ndarray):
        """Return pose landmarks or None. Used to place/scale the garment."""
        res = self._pose.process(rgb)
        return res.pose_landmarks
```

```python
"""FastAPI app: the VPS layer. Owns tokens, photo, live signaling, limits."""
from __future__ import annotations

import httpx
from fastapi import FastAPI, File, Form, HTTPException, UploadFile
from fastapi.responses import HTMLResponse, JSONResponse, Response
from fastapi.staticfiles import StaticFiles
from pathlib import Path

from .config import settings
from . import limits, consent
from pipeline import garment as garment_mod
from pipeline import photo_tryon

app = FastAPI(title="Virtual Try-On")


@app.get("/health")
def health():
    return {"ok": True, "brand": settings.brand_name,
            "live_backend": settings.live_backend}


@app.get("/usage")
def usage():
    return limits.usage_snapshot()


@app.post("/garment/prepare")
async def garment_prepare(file: UploadFile = File(...),
                          store_id: str = Form(...)):
    raw = await file.read()
    out = Path(settings.recordings_dir).parent / "garments" / store_id
    info = garment_mod.prepare_garment(raw, file.filename or "g.png", str(out))
    return info


@app.post("/photo/tryon")
async def photo_tryon_ep(person: UploadFile = File(...),
                         garment: UploadFile = File(...),
                         category: str = Form("tops")):
    p = await person.read()
    g = await garment.read()
    out = photo_tryon.run(p, g, category)
    return Response(content=out, media_type="image/png")


@app.post("/live/token")
async def live_token(store_id: str = Form(...),
                     consented: bool = Form(False),
                     is_adult: bool = Form(True)):
    """Start a live session. Enforces limits + consent. Returns a client token.
    For LIVE_BACKEND=decart the real key stays here; browser gets a scoped token.
    """
    try:
        limits.check_and_reserve_session(store_id)
        consent.require_consent(consented, is_adult)
    except (limits.LimitError, consent.ConsentError) as e:
        raise HTTPException(status_code=429, detail=str(e))

    if settings.live_backend == "decart":
        if not settings.decart_api_key:
            raise HTTPException(500, "DECART_API_KEY not set")
        # TODO: call Decart's session-token endpoint server-side and return a
        # short-lived, domain-scoped client token + model id. Never return the
        # raw DECART_API_KEY. See decart docs /getting-started.
        async with httpx.AsyncClient(timeout=15) as client:
            # placeholder shape; adjust to Decart's actual token API
            return {"backend": "decart", "model": settings.decart_model,
                    "max_seconds": settings.max_session_seconds,
                    "client_token": "TODO_scoped_token"}
    else:
        return {"backend": "local", "engine_url": settings.gpu_engine_url,
                "max_seconds": settings.max_session_seconds}


@app.post("/live/end")
async def live_end(store_id: str = Form(...), seconds: float = Form(0.0)):
    limits.record_seconds(store_id, seconds)
    return {"ok": True}


app.mount("/", StaticFiles(directory="web", html=True), name="web")
```
